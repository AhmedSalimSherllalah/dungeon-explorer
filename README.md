# CS1OP-TextGame - Dungeon Explorer

## Description
A text-based dungeon adventure game built in Java. You play as an adventurer who must fight through a dungeon, solve a puzzle and defeat a Dragon to escape.

## Requirements
- Install Java from https://www.oracle.com/java/technologies/downloads/
- Install VS Code from https://code.visualstudio.com

## How to Run
1. Open the project folder in VS Code
2. Press Ctrl and the backtick key to open the terminal
3. Type this to compile: javac -d out src/*.java
4. Type this to run: java -cp out Main
5. Type 1 or 2 to play

## Assumptions
- The player must defeat the enemy in a room before moving on
- Items are used immediately when picked up
- The puzzle must be solved before proceeding to the next stage
